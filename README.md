# Chukwudi Nwachukwu — Personal Calling Card Website

A one-page personal calling-card website for **Chukwudi Nwachukwu**, a Business Administration student at Lehman College (CUNY), B.B.A. expected 2030.

🌐 **Live site:** https://chukwudi-beta.vercel.app/

## About the site

A clean, single-page personal site presenting Chukwudi's background and strengths:

- **Practical Projects** — *Job Search Command Center* (a tracker for organizing applications, follow-ups, and progress) and *Campus Event Budget Planner* (a budgeting tool for planning event costs)
- **Beyond the Classroom** — Home Health Care (current role) and GRAMMY U Ambassador (Recording Academy)
- **Strengths** — Organization, Excel, Customer Relations, Data Tracking, Budgeting, Operations
- **Looking for remote opportunities** — open to remote roles applying organization, Excel, and customer relations skills

Built with [v0](https://v0.app) and deployed on [Vercel](https://vercel.com) (free plan). The site's footer reads: "Built with v0 as part of the Handshake AI Skills Studio."

## Tech stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- pnpm

## Run locally

```bash
pnpm install
pnpm dev
```

Then open http://localhost:3000.

## Deploy

Connect this repository to a Vercel project to deploy automatically from the `main` branch.
